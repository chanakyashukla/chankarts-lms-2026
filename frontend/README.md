# ChankArts Music Academy

Official digital frontend for ChankArts Music Academy.

**Learn. Create. Perform.**

## Production URL

https://chankarts.com/academy/

## Current UI

- Welcome / Landing Page
- Login
- Register (Multi-step with programme selection)
- Forgot Password

## Features

- Official ChankArts Music Academy branding
- Dark theme with gold accents
- Responsive design (mobile-first)
- Client-side SPA routing
- Multi-step registration with course catalogue
- Programme selection with multiple enrolment support

## Local Preview

```bash
# Navigate to project
cd chankarts-academy

# Start local server
python3 -m http.server 8000

# Open in browser
open http://localhost:8000/academy/
```

## Tech Stack

- HTML5
- CSS3 (Custom Properties)
- Vanilla JavaScript (ES6+)

## Backend Integration

Backend authentication and LMS functionality will be integrated in future phases. The current frontend is UI-only.
